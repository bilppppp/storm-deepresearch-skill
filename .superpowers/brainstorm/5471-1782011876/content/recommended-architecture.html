职责边界

Agent 负责判断

  • 澄清研究问题与边界
  • 自适应选择研究视角
  • 调用可用搜索/浏览工具
  • 解释冲突与形成综合判断

脚本负责确定性

  • 初始化目录与 Schema 校验
  • 引用 ID、Claim ID 与证据闭环
  • 占位符、泄漏、新鲜度与格式门禁
  • MD/HTML/PDF 构建及一致性检查

第一版明确不做

不内置付费搜索服务，不绑定某个模型供应商，不承诺“拒绝所有幻觉”，不把固定五角色当成事实来源，不加入 DOCX/视觉插图等与当前目标无关的扩展。
