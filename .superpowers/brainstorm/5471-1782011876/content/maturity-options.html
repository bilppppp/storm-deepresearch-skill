STORM DeepResearch 应该升级到哪一级？

选择的是工程边界，不是功能多少。推荐 B：公开可复用、可验证、可维护。

A · Personal Production
研究问题 → 来源登记 → 综合报告
Markdown → HTML → PDF
单机冒烟检查

A. 个人生产工具

重点是自己能稳定用。修复导出和验证器，但不建设完整版本治理与基准测试。

B · Reusable Library · 推荐
Brief + 自适应视角 + 检索计划
证据账本 → 主张闭环 → 矛盾/不确定性
确定性导出器 → MD / HTML / PDF
触发测试 + 输出评测 + 回归基线

B. 可公开复用的 Library

把“研究协议”升级成可安装系统：明确接口、可重复验证、真实样例、版本与维护周期。

C · Governed High Risk
B 的全部能力
领域政策 → 法律/医疗/投资边界
双人复核 + 发布审批 + 审计日志
到期复审 + 风险豁免

C. 高风险研究系统

适合输出会直接影响法律、医疗、投资决策的场景。最稳，但成本最高，必须有人类审批。

当前诊断

现版本是“协议完整、执行证据薄弱”：治理 42/100；入口无 frontmatter；无真实 eval；验证器会把带占位符、无 PDF 的空包判定为成功。
